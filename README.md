# Clean & Classy Cleaning Services

A simple, polished website for a cleaning business, ready to be published with GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — full site styling
- `script.js` — small client-side validation for the contact form

## Local preview
Open `index.html` in a browser, or run a simple local server such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
1. Push these files to your repository.
2. In GitHub, open `Settings` → `Pages`.
3. Set the source to `Deploy from a branch`.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and wait for the site to publish.

Your site will be available at:
`https://<your-username>.github.io/<repository-name>/`
